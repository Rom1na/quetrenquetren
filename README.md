# 🚇 QueTrenQueTren - Estado en Tiempo real de trenes que operan AMBA

Una aplicación web interactiva que informa los arribos a las estaciones de la red de Trenes que integran:
* **Linea Roca**
* **Linea Sarmiento**
* **Linea Mitre**
* **Linea San Martin**
* **Linea Belgrano Sur**
* **Tren de la Costa**

## 🌟 Características

* **Información de arribo a estaciones:** A través de la lógica Linea-Ramal-Estación permite consultar el horario de arribo a las estaciones.
* **Mapa Interactivo:** Ubicación geográfica de las formaciones a través de GoogelMaps 
  [GoogleMaps](https://www.google.com/maps)
* **Estaciones habituales** Permite tener un listado de las estaciones que usamos con más asiduidad para acceder más rápido a la información.

## 🛠️ Stack Tecnológico

* **React + Vite:** Para una interfaz rápida y reactiva.

## 📊 Fuente de Datos

Este proyecto utiliza el **Proyecto de Ariel Aguirre**.
* DOCS: [API Trenes](https://trenes.sofse.apidocs.ar/)
* Permite el acceso público a la API de Trenes de SOFSE - como explica en la docu.
